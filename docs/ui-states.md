# UI 边界状态约定

边界状态与正常内容共用字体、颜色、间距和操作尺寸。新增页面或交互时，必须一起设计恢复路径，不能只覆盖成功截图。

## 共享组件

| 场景 | 使用方式 | 行为要求 |
| --- | --- | --- |
| 首次加载 | `Loading` | 只在真正等待首次数据时显示；失败后不能继续显示加载文案。 |
| 局部读取失败 | `ErrorNotice source="read"` | 保留诊断详情与读取重试；同类故障已由连接提示说明时，不再重复展示。 |
| 操作失败 | `ErrorNotice`（默认 `source="action"`） | 发送、保存、导入等失败留在操作附近；连接提示不能掩盖操作结果，等待时禁用重复点击。 |
| 共享连接故障 | `WorkspaceConnectionNotice` | 当前页面或最上层弹窗只保留一处，使用提醒色；保留已加载内容和编辑，恢复后自动同步读取。 |
| 暂停、未配置、部分结果 | `StatusNotice` | 简短标题说明当前状态，正文交代影响，有恢复动作时放在同一区域。 |
| 空列表、无匹配项 | `Empty` | 仅在读取成功后显示；区分从未创建和筛选无结果。 |
| 必填、格式、范围错误 | `Input` / `Textarea` / `Select` | 使用真实 HTML 约束，提交时在字段旁显示错误并聚焦第一处错误；纠正后清除。 |
| 图片失败 | `ContentImage` | 保留图片的位置及原有编辑、预览或下载入口；显示可访问的失败说明。页面背景有独立的失败处理。 |
| 进度 | `ProgressBar` | 使用真实完成数量；不能把失败数量当成成功数量。无有效总量时不显示虚假的完成比例。 |
| 保存及离开 | `EditorForm`、现有表单关闭保护 | 保存中禁止重复提交和关闭；未保存输入必须经过明确的放弃确认。 |

说明性文字、消息注释、轻量“已保存”标签继续使用各自的文字层级，不应全部包装成提示卡片。

## 界面排版与密度

界面字号统一读取 `tokens.css` 的 `--ui-*` 变量。表单标签、输入值和选项值共用 `--ui-field-size`，桌面为 13px，手机为 16px；帮助文字使用 `--ui-caption-size`，分别为 12px、13px。不要在单个原生 select 或输入框上另设更大的字号，造成标签和值不协调。按钮、分组标题、弹窗标题与页面标题使用各自的共享层级。阅读正文继续遵守独立的阅读偏好。

桌面操作控件通常高 36px，选项卡约 36px；手机或触控环境保留至少 44px 的主要点击区域。通过减少重复说明、卡片嵌套和多余上下间距提升密度，不压缩触控区域。普通表单组间距采用 16px，弹窗内边距通常为 20px。

一般设置内容区随可用宽度伸展，最大 1040px；模型与子代理管理使用完整可用宽度。列表中名称、能力、状态和操作分别占用明确的列，避免把所有信息堆在左端。相关短字段在宽弹窗中成对排列，窄屏转为单列。标题与其说明保持紧邻，次要信息使用较小、较淡的文字，不另做大卡片。

简短设置弹窗按内容定高并限制最大高度；长编辑器内部滚动，保存操作保持可达。手机上短选择器使用底部面板，长编辑器使用完整可用空间。模型切换复用 `ModelSelect`：桌面在触发按钮旁展开，手机使用同一份搜索、分组、能力与继承选项。主模型、Writer、任务子代理和会话覆盖不得各自维护一套选择交互。

## 阅读排版

所有通过 `Markdown` 展示的正文共用 `.prose` 阅读样式，包括用户消息、普通回复、剧情与开场、生成预览与保留草稿、资料、总结和轨迹中的正文。字体、字号、行高和最大正文宽度读取全局阅读偏好，不按消息类型、所在面板或手机断点覆盖为固定值。窄容器按可用空间收缩。

正文标题使用相对字号并继承阅读行高；代码保留等宽字体，代码与表格的字号按正文字号缩放。界面标签、操作按钮、输入表单和原始诊断记录使用各自的界面排版。阅读设置中的正文预览使用尚未保存的草稿值，保存后更新所有会话和资料正文。

对白与斜体分别保存高亮开关及颜色，默认使用橙色与青碧色，各自提供适配浅色和深色外观的配色。斜体配色应用于所有 Markdown 正文；关闭着色仍保留倾斜效果。两种格式重叠时，已开启的斜体颜色优先，否则恢复对白颜色。预览与正文遵守相同规则。

正文渲染支持含中日韩文字的单星号强调，识别紧接后文的中文标点和结束星号前的横向空白。仅修复同一行正文中配对的单星号，不修改存储内容或模型输入；转义星号、实体星号、代码、链接、HTML 和未配对符号保持原有解释。中文字体没有原生斜体时，仅在正文强调元素上允许合成倾斜。

## 语义提示色

提示色统一使用 `apps/web/src/styles/tokens.css` 中的变量；每组都有前景色、`-soft` 背景和 `-border` 边框，并提供浅色、深色主题值。

| 状态 | `StatusNotice` tone | 颜色变量 | 表达方式 |
| --- | --- | --- | --- |
| 成功 | `success` | `--success` 绿色 | 勾选与明确的完成文案 |
| 需要注意、补全配置 | `warning` | `--warning` 琥珀色 | 警告三角与下一步说明 |
| 暂停 | `paused` | `--warning` 琥珀色 | 暂停图标与当前影响 |
| 信息、处理中 | `info` / `busy` | `--info` 蓝色 | 信息图标或真实加载状态 |
| 失败 | `error` | `--danger` 红色 | 错误图标、实际原因与恢复入口 |

卡片使用淡色背景、细边框和彩色标题/图标；列表状态只为短标签和图标着色。未测试、普通帮助文字保持中性，不暗示成功或失败。颜色与文字、图标共同说明状态；浅色和深色模式下，状态文字与背景对比度至少 4.5:1。保留现有错误 `alert` 与一般状态 `status` 播报、加载动效和减少动画偏好。缺少密钥使用提醒色，实际模型调用失败使用错误色。

## 数据与上下文

- 首次失败与后台刷新失败分开处理。有旧数据时保持页面或表单挂载，按上述归属显示反馈。不要通过错误分支卸载编辑器而丢失草稿。
- HTTP 成功但响应不可解析也属于失败，应显示恢复入口；不能因缺少数据永远停留在加载状态。
- 重试只恢复相应读取或明确失败的操作，不能意外重复提交生成、保存或导入。
- 后台查询失败通过已有登录状态读取确认是否为共享连接故障。只有同类网络、服务、限流或响应解析故障可以合并；权限、资料不存在、冲突和校验失败继续由具体区域说明。
- 连接恢复时补读仍在使用的失败查询；不重放操作、不刷新未打开的区域。待发消息列表同样参与恢复，避免连接恢复后留下无效错误。
- Prompt 预览的 POST 只计算资料，不修改会话，按读取处理；失败时保留当前编辑，并参与上述读取恢复。
- SSE 单独断连时由会话顶部的一条轻量状态说明重连；共享连接故障出现时收起它。运行进展与底部活动标记不重复提示断连，也不推断服务端生成一定仍在继续。
- 弹窗打开后，连接反馈移到最上层弹窗。模型选择、删除确认等局部错误也应由当前操作区域负责，不在弹窗内外重复展示。
- 批量操作分别记录成功、重复和失败。隐藏进度只收起展示，不丢弃正在运行的任务与结果；结束后应能重新打开结果并查看相关资料。
- 资料不存在时不能显示“读取中”；文件无内容时不能虚构行数；预览失败时不能声称正在展示当前编辑内容。
- 错误原文与用户资料均作为文本处理；很长的诊断使用现有可展开区域，保持主要操作可见。

## 页面验收

覆盖全部会话、资料库、新会话、会话正文与资料面板、设置分类及相关弹窗。每个异步区域至少验证：首次加载、首次失败、重试等待、成功恢复、后台刷新失败、有/无旧数据。每种编辑器至少验证：空必填、非法格式或范围、保存中、保存失败、放弃/继续编辑。

桌面与手机分别检查，额外覆盖短视口、长名称/文件名、深色主题、英文、减少动画偏好、键盘焦点、图片失败、批量部分成功。检查可见尺寸及实际操作；只检查 class 名称或 DOM 存在不能代替浏览器验收。

使用项目独立的合成数据环境。构建、相关功能测试、浏览器截图与恢复检查均完成后记录验收结果，个人数据不得进入测试夹具或公开文档。
