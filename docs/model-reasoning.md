# 模型与思考强度

新增模型默认自动识别显示名称、图片输入、思考能力、上下文窗口和最大输出。添加连接后自动读取服务模型列表，同时保留服务明确返回的能力信息；没有服务信息时，按准确模型 ID、协议和地址匹配本项目锁定的 Pi 模型目录。自定义连接名称不影响识别。模型列表及能力信息不代表已经验证调用成功。

支持思考的模型默认开启思考，优先使用“中”；模型不提供这一档时，按低、高、极低、极高、最高的顺序选择可用档位。界面显示实际默认值。明确选择的档位不做静默降级；切换模型时清除旧模型的会话强度，让新模型使用自己的默认值。

## 设置入口

- 会话输入栏：点击模型名称打开可搜索、按连接分组的选择器；模型名称旁直接显示当前思考强度。电脑使用按钮旁的浮层，手机使用底部面板。
- 设置 → 模型 → 默认主模型：设置全局默认模型和强度；会话可以继承或覆盖。
- 会话顶部 → 子代理：分别为 Writer 和每个任务子代理选择模型、强度。跟随主模型时也能单独覆盖强度，或者恢复全局默认。
- 设置 → 子代理：保存 Writer 和任务子代理的全局设置。跟随主模型的独立强度在每次调用时，按所在会话的实际模型校验。

强度菜单只展示该模型支持的档位，并提供默认/继承选项。主模型、Writer、任务子代理各自解析自己的有效强度，互不覆盖；这些会话设置随事件记录、分支和数据库备份保存。正在生成时不能修改本会话的模型与强度。

## 自动识别与手动覆盖

设置 → 模型 → 对应模型“配置”中，图片输入和思考能力分别提供自动、手动开启、手动关闭；名称和长度字段留空表示自动。每项显示自动值的来源，手动设置优先于服务信息，服务信息优先于模型目录。输出预算和温度属于生成偏好，可以留空使用应用或服务默认值。

已有显式配置保留。“恢复自动”可一起清除名称、图片、思考和长度的手动覆盖；也可以逐项恢复。自动值不会在保存或重启时被固定为手动值。

“刷新识别”重新读取服务能力，在保存前只预览结果，不改变运行中的模型。识别结果与具体连接、协议和密钥绑定；更换地址或密钥后需要重新获取。已保存的能力随数据库备份和恢复，重启时不依赖外部服务。

服务未返回信息且目录未收录的模型或自定义别名会明确提示未识别。未知能力暂不开启，未知长度显示应用暂用值；确认服务支持后可以手动设置。不会根据名称中的 “vision” 等词或去掉网关前缀猜测能力。聚合服务可能改变原模型的能力和参数，服务不接受时会报告实际调用失败。

在初始 `config/models.json` 中省略 `label`、`input`、`reasoning`、`contextWindow`、`maxTokens` 表示自动识别，写入值表示手动覆盖。自定义服务仍需提供准确的 `api` 和 `baseUrl`。服务字段解析依据 [OpenRouter 模型信息](https://openrouter.ai/docs/guides/overview/models)、[Claude Models API](https://platform.claude.com/docs/en/api/models) 和 [Cline 能力说明](https://docs.cline.bot/api/models)；只识别明确的能力字段，不通过生成请求探测。

Pi 0.85.0 尚未收录 `gpt-6-astra`，本项目按 [GPT-6 Astra 官方模型说明](https://developers.openai.com/api/docs/models/gpt-6-astra)补充准确 ID 的低、中、高、极高、最高档位（核对日期：2026-09-08）。不提供模型不支持的关闭/极低档位。未知名称不按前缀猜测。此补充只覆盖思考能力；服务是否支持相应协议、工具及其他参数仍需与连接配置匹配。

模型与强度相邻、就地切换的交互参考 [Codex 模型选择说明](https://learn.chatgpt.com/docs/models)。这里的强度始终对应单次模型调用参数；任务子代理继续由项目自身的配置和编排控制。
