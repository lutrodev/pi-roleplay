# RP Skills

`builtin/` 包含从原项目审查迁入的七份 RP 指导和状态协议参考，来源指纹记录在 `docs/source-provenance.json`。构建镜像时同时交付给应用和工具服务，模型使用 `/skills/builtin/<名称>` 读取参考文件。

部署者的自定义 Skills 单独放在持久数据目录，分别只读挂载到应用和工具服务的 `/skills/custom`。不得挂载到整个 `/skills`，否则会遮住内置指导。每个 Skill 使用独立目录和带 YAML 元数据的 `SKILL.md`，脚本和参考文件放在同一目录内。

一次执行固定所发现的指导正文和摘要指纹，加载后可通过文件工具读取参考内容。脚本只通过工具服务的 Bash 执行。Skill 本身不授予额外工具或保存资料的权限；无效文件、同名冲突和不可读目录会在设置中显示诊断。

`disable-model-invocation: true` 允许只由用户 `/名称` 调用；`user-invocable: false` 用于模型加载的辅助指导。两者均未设置时支持两种调用。子代理有独立加载记录，不能代替父模型满足资料工具的指导前置要求。
